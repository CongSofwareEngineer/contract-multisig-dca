# Swap V3
- **Date**: 2026-10-15
- **Feature**: swap-v3 (→ docs/instruction/swap-v3.md)
- **Type**: Added
- **Files**: `src/vault/DCAVaultSwap.sol`, `src/vault/DCAVaultRoles.sol`, `src/vault/DCAVaultStorage.sol`, `src/DCAVault.sol`, `test/DCAVault.t.sol`, `test/DCAVault.security.t.sol`, `test/helpers/VaultTestBase.sol`, `test/DCAVault.fork.t.sol`
- **What**:
  - **Daily volume cap (shared with V4)**: every `swapExactInputV3` / `swapExactInputV4` adds its stable side (buy: `amountIn`, sell: measured `amountOut`) to `dailyVolumeUsed` for the current UTC day (`block.timestamp / 1 days`) inside `_settleSwap`; going past `dailyVolumeCap` reverts `DailyVolumeExceeded` (whole tx, stable stays in Morpho). New state `dailyVolumeCap`, `volumeDay`, `dailyVolumeUsed`; event `DailyVolumeCapChanged(oldCap, newCap)`. Cap set by a new constructor arg `_dailyVolumeCap` (deploy default 600 USDC) and changed by the new `SetDailyVolumeCap` proposal ([proposal-system](2026-10-15_proposal-system.md)).
- **Tests**: added `test_Constructor_SetsDailyVolumeCap`, `test_SetDailyVolumeCap_ViaProposal`, `test_SetDailyVolumeCap_HelperMatchesPropose`, `test_Revert_Propose_SetDailyVolumeCapBadData`, `test_SwapExactInputV3_BuyCountsTowardsDailyCap`, `test_SwapExactInputV4_SellCountsStableReceived`, `test_DailyVolume_ResetsNextUtcDay`, `test_SetDailyVolumeCap_ZeroBlocksSwaps`, `test_SetDailyVolumeCap_LowerThanUsedBlocksRestOfDay`, `test_Security_OperatorChurnBoundedByDailyCap`. Test base deploys with a large `DAILY_CAP`; fork tests with 100,000 USDC. `forge test`: 235 passed, 0 failed (incl. 17 Base fork tests).
- **Why**:
  - Owner request after the 2026-10-15 review: a leaked operator key could churn buy/sell at fair prices to burn the vault through pool fees (no capital, no 7702, invisible to a price monitor), and sandwich listed pools without any volume limit. Counting both directions caps fee churn and sandwiched buys at `dailyVolumeCap` per day. Known gap (same-day re-review): a sandwiched sell is counted by the ~0 stable received, so it is not bounded — fix pending owner decision. Replaces the earlier spec §7 decision "no per-day caps".
