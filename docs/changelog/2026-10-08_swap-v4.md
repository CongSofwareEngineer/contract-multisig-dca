# Swap V4
- **Date**: 2026-10-08
- **Feature**: swap-v4 (→ docs/instruction/swap-v4.md)
- **Type**: Added, Changed
- **Files**: `src/vault/DCAVaultSwap.sol`, `src/vault/DCAVaultSwapV3.sol`, `src/vault/DCAVaultSwapV4.sol`, `src/vault/DCAVaultStorage.sol`, `src/vault/DCAVaultRoles.sol`, `src/vault/DCAVaultProposals.sol`, `src/DCAVault.sol`, `src/interfaces/IPermit2.sol`, `src/interfaces/IUniversalRouter.sol`, `src/interfaces/IV4Router.sol`, `script/Deploy.s.sol`, `.env.example`, `test/DCAVault.t.sol`, `test/DCAVault.security.t.sol`, `test/DCAVault.fork.t.sol`, `test/helpers/VaultTestBase.sol`, `test/mocks/MockPermit2.sol`, `test/mocks/MockUniversalRouter.sol`, `DCA_VAULT_SPEC.md`
- **What**:
  - **swapExactInputV4**: implemented (no longer a stub; `NotImplemented` error removed). The vault builds `V4_SWAP` (`SWAP_EXACT_IN_SINGLE` + `SETTLE_ALL` + `TAKE_ALL`) itself, `hooks = address(0)`, exact ERC20 → Permit2 and Permit2 → UniversalRouter approvals (Permit2 expiring this block) reset to 0 after the call, balance-delta checks (spent ≤ amountIn, received ≥ minOut), sell-to-USDC auto-supplied to Morpho, `Swapped(..., version 4)`. Uses the same checks as V3 (shared `_checkSwap` / `_settleSwap`).
  - **Native ETH**: whitelisting `address(0)` enables V4 native-ETH pools (`currency0 = address(0)`). Selling ETH sends exactly `amountIn` as `msg.value` to `UniversalRouter.execute` (no Permit2 / ERC20 approval). Buying ETH opens `receive()` only for the duration of the swap (`_expectingNative`), since the PoolManager pays ETH to the vault on `TAKE_ALL`. Balances read via `address(this).balance`. ETH stays idle in the vault.
  - **allowedTickSpacing**: new whitelist `allowedTickSpacing[int24]`, seeded by a new constructor arg `_tickSpacings[]`, changed via new proposal `SetAllowedTickSpacing(int24, bool)` (appended to the enum) / `proposeSetAllowedTickSpacing`; range `1..32767`; event `TickSpacingAllowed`.
  - **Addresses**: `permit2` / `universalRouter` are state, changeable only via threshold `ChangePermit2` / `ChangeUniversalRouter` proposals.
- **Tests**: unit `test_SwapExactInputV4_*` (buy, sorted hookless PoolKey, sells + Morpho, current router addresses) and `test_Revert_SwapExactInputV4_*` (tick spacing, fee, pair, token, minOut, deadline, balance, uint128, not operator, slippage); `test_Proposal_SetAllowedTickSpacing`, `test_Revert_Proposal_SetAllowedTickSpacing*`, `test_Revert_Constructor_DuplicateTickSpacing` / `InvalidTickSpacing`; security: V4 in the invariant #1 fuzz, `test_Invariant1_V4RouterCannotPullMoreThanAmountIn`, `test_Invariant1_V4ShortOutputIsCaughtByBalanceDelta`, `test_Invariant3_V4Permit2AllowanceExpiresThisBlock`, V4 in invariants #2 / #3 / #8; fork (real UniversalRouter + V4 Quoter on Base): USDC→WETH 3000/60, USDC→cbBTC 500/10, WETH→USDC 500/10 + Morpho, slippage revert; native ETH: unit `test_SwapExactInputV4_BuyNative`, `test_SwapExactInputV4_SellNativeSuppliesStableToMorpho`, `test_Revert_SwapExactInputV4_SellNativeInsufficientBalance`, `test_Revert_SwapExactInputV4_NativeNotWhitelisted`; fork `test_Fork_SwapExactInputV4_UsdcToNativeEth`, `test_Fork_SwapExactInputV4_SellNativeEthAutoDepositsToMorpho` (real ETH/USDC 500/10 hookless pool). `forge test` (incl. Base mainnet fork): 193 passed, 0 failed (140 unit, 37 security, 16 fork).
