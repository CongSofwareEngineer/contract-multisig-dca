- **What**:
  - **swapExactInputV4**: implemented (no longer a stub; `NotImplemented` error removed). The vault builds `V4_SWAP` (`SWAP_EXACT_IN_SINGLE` + `SETTLE_ALL` + `TAKE_ALL`) itself, `hooks = address(0)`, exact ERC20 → Permit2 and Permit2 → UniversalRouter approvals (Permit2 expiring this block) reset to 0 after the call, balance-delta checks (spent ≤ amountIn, received ≥ minOut), sell-to-USDC auto-supplied to Morpho, `Swapped(..., version 4)`. Uses the same checks as V3 (shared `_prepareSwap` / `_settleSwap`). **Buy** (`tokenIn == stableToken`): after every check, withdraws exactly `amountIn` from Morpho (`MorphoWithdrawn`) and swaps in the same tx — no separate `morphoWithdraw` and no `withdrawAndSwapV4`; idle stable is not used; a failed swap reverts the whole tx so the stable stays in Morpho.
  - **Native ETH**: whitelisting `address(0)` enables V4 native-ETH pools (`currency0 = address(0)`). Selling ETH sends exactly `amountIn` as `msg.value` to `UniversalRouter.execute` (no Permit2 / ERC20 approval). Buying ETH opens `receive()` only for the duration of the swap (`_expectingNative`), since the PoolManager pays ETH to the vault on `TAKE_ALL`. Balances read via `address(this).balance`. ETH stays idle in the vault.
  - **Pool whitelist**: V4 swaps require `tickSpacing >= 1` (0 is the V3 marker) and `(token, fee, tickSpacing)` listed in the shared `allowedPool` whitelist (see swap-v3) — no independent fee / tick-spacing lists; `PoolNotAllowed`.
  - **Addresses**: `permit2` / `universalRouter` are state, changeable only via threshold `ChangePermit2` / `ChangeUniversalRouter` proposals.

- **Why**:
  - Owner request (2026-10-08): make `swapExactInputV4` work now instead of a stub, with `hooks = address(0)`.
  - Pool whitelist per `(token, fee, tickSpacing)`: 2026-10-08 security review — V4 pool creation is permissionless, so independent fee / spacing lists let a stolen operator key swap into its own rigged pool.
  - Buy pulls from Morpho (owner request, 2026-10-08): a V4 buy used to need two txs (`morphoWithdraw` + swap); merged into `swapExactInputV4` so it is one tx like V3.
  - Native ETH: owner request (2026-10-08) — Uniswap V4 uses `address(0)` for ETH and the owner must be able to whitelist it.
