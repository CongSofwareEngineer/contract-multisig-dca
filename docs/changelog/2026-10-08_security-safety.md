# Security & Safety
- **Date**: 2026-10-08
- **Feature**: security-safety (→ docs/instruction/security-safety.md)
- **Type**: Added, Changed
- **Files**: `src/vault/DCAVaultStorage.sol`, `src/vault/DCAVaultRoles.sol`, `src/vault/DCAVaultProposals.sol`, `src/vault/DCAVaultSwap.sol`, `src/vault/DCAVaultSwapV4.sol`, `src/vault/DCAVaultMorpho.sol`, `test/DCAVault.security.t.sol`, `test/DCAVault.t.sol`, `test/helpers/VaultTestBase.sol`, `test/mocks/JunkToken.sol`, `test/mocks/ReentrantMorphoVault.sol`, `test/mocks/MockUniversalRouter.sol`, `DCA_VAULT_SPEC.md`, `CLAUDE.md`
- **What**:
  - **Pause**: single-signer `pause()`, `Unpause` proposal.
  - **Stable / tradable split**: `stableToken` (one address) and `allowedToken` (tradable tokens) are disjoint lists; `StableNotTradable` in the constructor / `AddToken` / `ChangeStableToken`. `allowedToken` may hold `address(0)` (= native ETH, constant `NATIVE`). Any tradable token can be removed. Errors `UsdcNotAllowed`, `CannotRemoveUsdc`, `SameToken` removed. `getAllowedTokens()` / `getBalances()` read only the stable + whitelisted tokens.
  - **WithdrawBatch**: whitelisted `to`; each token is the stable or whitelisted; `max` support; stable shortfall pulled from Morpho; native ETH sent with `call{value}("")` to the whitelisted address (`NativeTransferFailed` on failure).
  - **Outflows**: tokens leave only to `isWithdrawAddress` or, on `ChangeMorphoVault`, to the vault a threshold of signers approved (not validated on-chain; covered by `test_Security_ChangeMorphoVaultNeedsThreshold`).
  - **Swap scope**: operator limited to stable ↔ whitelisted-token pools; V4 additionally limited to hookless pools (`hooks = address(0)`) with a whitelisted fee and tick spacing.
  - **V4 approvals**: ERC20 → Permit2 and Permit2 → UniversalRouter allowances are exact, Permit2 expires this block, both reset to 0 in the same call (invariant 3); `_assertNoAllowances` now checks both.
  - **ETH (invariant 10)**: no `fallback()`. `receive()` accepts ETH only while `swapExactInputV4` is buying native ETH (`_expectingNative` window); otherwise `UnexpectedNative`.
  - **Hardening**: no delegatecall/selfdestruct, nonReentrant on all external-touching functions. `cancel` now `onlySigner`, so every state-changing signer function checks the role (a removed signer keeps no power).
  - **Protocol address changes**: `uniV3Router` / `permit2` / `universalRouter` changeable only at threshold; the old router keeps no allowance after a switch.
  - **Accepted risks** (owner decision, documented in spec §16 and instruction §5): operator sandwich (`minOut > 0` only), all-or-nothing Morpho migration, 2 signers ⇒ threshold 1, stale `Unpause` proposals, protocol addresses not validated on-chain.
- **Tests**: one test group per §10 invariant (1–12) incl. fuzzed malicious operator, bytecode opcode scan, junk token, reentrancy, fake-vault migration, USDC-side swap fuzz; `test_Security_ChangeProtocolAddressesNeedThreshold`, `test_Security_OldRouterHasNoPowerAfterChange`; `test_Invariant1_OperatorCannotUseSignerFunctions` now also covers `reject` / `cancel` / `pause`; V4: fuzz action, `test_Invariant1_V4RouterCannotPullMoreThanAmountIn`, `test_Invariant1_V4ShortOutputIsCaughtByBalanceDelta`, `test_Invariant3_V4Permit2AllowanceExpiresThisBlock`, V4 steps in invariants #2 / #3 / #8; `test_Invariant10_RejectsEthWhenNativeWhitelisted`, `test_Invariant10_RouterCannotPushEthDuringErc20Swap`; unit `test_Revert_Constructor_StableInTokens`, `test_Revert_Proposal_AddStableAsToken`, `test_Revert_Proposal_RemoveStable`, `test_Proposal_AddRemoveNativeToken`, `test_WithdrawBatch_Native`, `test_Revert_WithdrawBatch_NativeNotWhitelisted`, `test_Revert_WithdrawBatch_NativeReceiverRejects`. `forge test` (incl. Base mainnet fork): 193 passed, 0 failed (140 unit, 37 security, 16 fork).
- **Why**:
  - Initial implementation of DCA_VAULT_SPEC.md §5.1b, §5.3 (pause, WithdrawBatch), §10.
  - Follow-up to the 2026-10-08 security review (owner decisions): add role checks everywhere, make Uniswap / Permit2 addresses changeable, keep sandwich + migration behavior as spec and document them as accepted risks.
  - Stable / tradable split + native ETH: owner request (2026-10-08) — one stablecoin for easy management, any tradable tokens, and native ETH (V4 `address(0)`) must be settable. `receive()` is limited to the native-buy window so invariant 10 still holds everywhere else.
