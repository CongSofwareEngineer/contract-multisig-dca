# Morpho Integration
- **Date**: 2026-10-08
- **Feature**: morpho-integration (→ docs/instruction/morpho-integration.md)
- **Type**: Added, Changed, Removed
- **Files**: `src/DCAVault.sol`, `src/vault/DCAVaultStorage.sol`, `src/vault/DCAVaultMorpho.sol`, `src/vault/DCAVaultProposals.sol`, `test/DCAVault.t.sol`, `test/DCAVault.security.t.sol`, `test/DCAVault.fork.t.sol`, `test/helpers/VaultTestBase.sol`, `test/mocks/MockMorphoVault.sol`, `test/mocks/ReentrantMorphoVault.sol`, `script/Deploy.s.sol`, `.env.example`, `DCA_VAULT_SPEC.md`, `CLAUDE.md`, `docs/instruction/roles-multisig.md`, `docs/instruction/swap-v3.md`, `docs/instruction/swap-v4.md`, `docs/instruction/deployment.md`
- **What**:
  - **Single stable**: the vault has exactly one stablecoin, `stableToken` (USDC), stored separately from the tradable-token list (replaces the immutable `usdc`). It is the only token deposited and the only token supplied to Morpho; bought tokens stay idle. Every "is it the stable?" check is an address compare against `stableToken`.
  - **depositAndSupply**: anyone, `stableToken` only, not paused-gated. Event `Deposited(from, amount, shares)`.
  - **morphoDeposit**: operator only, supplies idle stable, receiver hardcoded.
  - **morphoWithdraw removed**: no public Morpho withdraw — nobody (operator, signer, anyone) can call it. Stable leaves Morpho only via a buy swap (exact `amountIn`), `WithdrawBatch` (shortfall) or `ChangeMorphoVault` / `ChangeStableToken` (redeem all). Runtime size 23,578 B (998 B under EIP-170).
  - **ChangeMorphoVault**: threshold proposal only; redeem all → switch → supply whole stable balance (incl. idle). Only checks `newVault != 0` and `!= current` (both now already at propose time, re-checked at execute) — no factory / `asset()` validation on-chain (constructor too). No `morphoFactories` arg, no `getMorphoFactories()`, no `NotMorphoVault` / `VaultAssetMismatch` errors.
  - **ChangeStableToken**: new proposal `ChangeStableToken(newStable, newVault, to)` / `proposeChangeStableToken` (appended to the enum). On execute it redeems all old-vault shares, sends **every unit** of old stable to the whitelisted `to`, then switches `stableToken` and `morphoVault` together; event `StableTokenChanged`. `newStable` must not be a tradable token. Pool whitelist entries do **not** carry over (they are keyed by the stable): no swap runs for the new stable until signers `SetAllowedPool` its pools. It also sets `stableChangedAt`, which expires every proposal created at or before the switch.
  - **Views**: `totalStable()`; `getBalances()` → `(stableIdle, stableInMorpho, tokens[], balances[])` (stable reported separately, native ETH via `address(this).balance`).
  - **Accepted risk** (owner decision): migration stays all-or-nothing — a broken / illiquid old vault blocks `ChangeMorphoVault` (documented in spec §16).
- **Tests**: unit with OZ ERC4626 mock (migration, same-vault revert); security `test_Security_ChangeMorphoVaultNeedsThreshold` (operator / outsider cannot propose or vote, 1 signer vote does not change the vault, 2nd vote migrates); fork against Steakhouse bbqUSDC (Vault V2), migration to Gauntlet USDC Prime; `test_Proposal_ChangeStableTokenSweepsOldStable`, `test_Proposal_ChangeStableTokenCannotBeGriefedByDust`, `test_Revert_Proposal_ChangeStableTokenInvalid`, `test_Revert_Proposal_ChangeStableTokenWithdrawAddressRemovedBeforeExecute`, security `test_Security_ChangeStableTokenDropsOldPoolEntries`, `test_Security_ChangeStableTokenExpiresPendingProposals`, updated `test_GetBalances`. `test_Revert_MorphoWithdraw_NobodyCanCall` replaces the old morphoWithdraw unit tests; security fuzz / invariant #2 / #3 / #8 / #12 tests and the fork Morpho test now use `morphoDeposit` of idle stable or a buy swap instead; `ReentrantMorphoVault` re-enters via `morphoDeposit`. `forge test` (incl. Base mainnet fork): 215 passed, 0 failed.
- **Why**:
  - Initial implementation of DCA_VAULT_SPEC.md §5.1, §5.2, §5.3.
  - No on-chain vault validation: owner decision — the Morpho address is chosen by the multisig, the contract just supplies / withdraws there. Protection is the threshold vote on `ChangeMorphoVault`; signers verify the vault off-chain before approving.
  - Remove `morphoWithdraw`: owner request (2026-10-08) — buys already pull from Morpho, so the function was redundant and only let a compromised operator key move the stable out of Morpho.
  - Single stable + `ChangeStableToken`: owner request (2026-10-08) — one stablecoin is easier to manage; the stable may change, but only after everything in the old one is withdrawn. The sweep runs inside the proposal so a 1-wei donation cannot block the switch. Old pool entries dropped on the switch (2026-10-08 security review): otherwise they would silently open unvetted (newStable, token) pools to the operator.
