# Swap V3
- **Date**: 2026-10-08
- **Feature**: swap-v3 (→ docs/instruction/swap-v3.md)
- **Type**: Added, Changed, Fixed
- **Files**: `src/vault/DCAVaultSwap.sol`, `src/vault/DCAVaultSwapV3.sol`, `src/vault/DCAVaultSwapV4.sol`, `src/vault/DCAVaultStorage.sol`, `src/vault/DCAVaultRoles.sol`, `src/vault/DCAVaultProposals.sol`, `src/DCAVault.sol`, `src/interfaces/ISwapRouter02.sol`, `test/helpers/VaultTestBase.sol`, `test/DCAVault.security.t.sol`, `test/DCAVault.t.sol`, `test/DCAVault.fork.t.sol`, `test/mocks/MockSwapRouter.sol`, `DCA_VAULT_SPEC.md`
- **What**:
  - **swapExactInputV3**: single entry point for buys and sells. **Buy** (`tokenIn == stableToken`): after every check, withdraws exactly `amountIn` from Morpho (`MorphoWithdrawn`) and swaps in the same tx; idle stable is not used; a failed swap reverts the whole tx so the stable stays in Morpho. Whitelisted tokens + fee, deadline checked in-contract, atomic approve, recipient = vault, output measured by balance delta, sell → auto-deposit proceeds to Morpho. **One side must be `stableToken`** (`PairNotAllowed` otherwise), the other must be in `allowedToken` (`TokenNotAllowed`): only cbBTC/USDC and WETH/USDC pools run, no WETH ↔ cbBTC. Native ETH (`address(0)`) is rejected on V3 (`NativeNotSupported`).
  - **withdrawAndSwapV3**: removed — merged into `swapExactInputV3` (a buy now pulls from Morpho itself). `_swapV3` inlined into `swapExactInputV3`.
  - **Pool whitelist (`allowedPool`)**, shared by V3 and V4: one entry = one pool `(token, fee, tickSpacing)` vs the stable, `tickSpacing = 0` (`V3_POOL`) = V3 pool, `>= 1` = hookless V4 pool. Seeded by constructor `PoolConfig[] _pools`, changed via `SetAllowedPool` proposal; event `PoolAllowed`, error `PoolNotAllowed`; fee `1..1_000_000`, spacing `0..32767`, no stable-side entry, no V3 entry for native ETH. Entries are stored **per stable** (`_allowedPool[stable][token][fee][tickSpacing]`, internal; view `allowedPool(token, fee, tickSpacing)` reads the current stable), so `ChangeStableToken` drops every entry; event `PoolAllowed(stable, token, fee, tickSpacing, allowed)`. No on-chain list (size limit) — rebuild from events. Replaces the independent `allowedFee` / `allowedTickSpacing` lists (`FeeNotAllowed`, `FeeAllowed`, `SetAllowedFee` gone). V3 now rejects native ETH before the pool check.
  - **Shared swap helpers**: checks + Morpho pull on a buy in `_prepareSwap`, balance-delta / `Swapped` / sell-to-Morpho moved to `_settleSwap`, both reused by `swapExactInputV4`; V3 behavior unchanged. the pool whitelist also gates V4 swaps.
  - **Router address**: `uniV3Router` is now state, changeable only via a threshold `ChangeUniV3Router` proposal; `swapExactInputV3` reads the current value.
- **Tests**: every revert path, buy/sell; `test_Revert_SwapExactInputV3_NonUsdcPair`, `testFuzz_Security_SwapNeedsUsdcSide`; fork: USDC→WETH (500, QuoterV2 minOut), USDC→cbBTC (500), WETH→cbBTC rejected (`test_Fork_Revert_SwapExactInputV3_WethToCbbtc`), slippage revert; `test_Proposal_ChangeUniV3RouterSwapsUseNewRouter`, `test_Security_OldRouterHasNoPowerAfterChange`; `test_Revert_SwapExactInputV3_Native`, `test_Revert_SwapExactInputV3_BuyNative`, `test_Revert_SwapExactInputV3_BuyTokenOutStable`, stable → stable now `TokenNotAllowed`. Buy-from-Morpho: `test_SwapExactInputV3_BuyWithdrawsExactAmountFromMorpho`, `test_SwapExactInputV3_BuySwapFailureKeepsUsdcInMorpho`, `test_Revert_SwapExactInputV3_BuyMoreThanMorphoReverts`, `test_Revert_SwapExactInputV3_BuyZeroAmount`; `InsufficientBalance` now tested on the sell side; fork `test_Fork_SwapExactInputV3_Buy*`. `forge test` (incl. Base mainnet fork): 215 passed, 0 failed. - **Why**:
  - Initial implementation of DCA_VAULT_SPEC.md §5.2 and §7. Balance-delta check added so a misbehaving router's return value can't be trusted blindly.
  - Changeable router: owner request (2026-10-08 security review) — Uniswap addresses must be replaceable without redeploying.
  - Shared helpers: V4 swap implemented with the same rules (owner request, 2026-10-08) — one code path for the checks avoids V3/V4 drift.
  - USDC-side rule: owner decision — only the BTC/USDC and ETH/USDC pools may be used; reduces the pools a compromised operator can route value through.
  - Buy pulls from Morpho inside `swapExactInputV3` (owner request, 2026-10-08): one function for buy and sell, a buy is one tx, and less bytecode (EIP-170 margin 338 B → 784 B).
  - Stable / tradable split: owner request (2026-10-08) — one stable compared by address, tradable tokens kept in their own list.
  - Pool whitelist: 2026-10-08 security review — with independent fee / tick-spacing lists a stolen operator key could route the whole vault into a fresh, attacker-seeded pool (e.g. V4 USDC/WETH 500/60, permissionless to create) with `minOut = 1` and drain it without capital. Owner chose one entry per pool `(token, fee, tickSpacing)` — readable numbers, no PoolId lookup.
  - Pool whitelist keyed by stable: 2026-10-08 security review — with entries keyed only by token, `ChangeStableToken` silently re-pointed every entry at the (newStable, token) pool, which nobody vetted and may not exist yet; a stolen operator key could create it at a rigged price and swap the whole vault in with `minOut = 1`. Owner chose to add the stable to the key. EIP-170 margin 1,029 B → 1,045 B.
